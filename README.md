# Parkinson’s Disease Detection — AI/ML Academic Project

An educational and clinical research demonstration application for screening acoustic vocal dysphonia measurements to detect early signs and biomarker patterns associated with Parkinson's disease.

> **IMPORTANT CLINICAL DISCLAIMER:**
> This application is strictly an educational and academic demonstration. The predictions generated by the machine learning model are **not** medical diagnoses. Users, patients, and healthcare providers must always consult qualified medical professionals and neurologists for formal diagnostic assessments.

---

## 🌟 Overview & Key Features

1. **Academic Authentication & Session Management**:
   - Secure demo sign-in and account registration.
   - Pre-configured 1-tap reviewer credentials (`researcher@medical-ai.edu`).
   - Remember Me preference and demo password recovery workflow.

2. **Dedicated Clinical Voice Feature Input (22 Metrics)**:
   - Full support for the Oxford University / UCI Parkinson's Voice dataset feature suite:
     - **Pitch & Fundamental Frequency**: `MDVP:Fo(Hz)`, `MDVP:Fhi(Hz)`, `MDVP:Flo(Hz)`
     - **Cycle-to-Cycle Frequency Perturbation (Jitter)**: `MDVP:Jitter(%)`, `MDVP:Jitter(Abs)`, `MDVP:RAP`, `MDVP:PPQ`, `Jitter:DDP`
     - **Cycle-to-Cycle Amplitude Perturbation (Shimmer)**: `MDVP:Shimmer`, `MDVP:Shimmer(dB)`, `Shimmer:APQ3`, `Shimmer:APQ5`, `MDVP:APQ`, `Shimmer:DDA`
     - **Turbulence & Harmonics**: `NHR` (Noise-to-Harmonics Ratio), `HNR` (Harmonics-to-Noise Ratio)
     - **Nonlinear Dynamical Complexity**: `RPDE` (Recurrence Period Density Entropy), `DFA` (Detrended Fluctuation Analysis), `spread1`, `spread2`, `D2` (Correlation Dimension), `PPE` (Pitch Period Entropy)
   - 1-Tap Benchmark Presets for Healthy Subject and Parkinson's-Detected Subject for rapid evaluation.

3. **Machine Learning Model Engine**:
   - Calibrated decision boundary based on published biomedical engineering weights (Little et al., Oxford University).
   - Computes probability score $P(\text{Parkinson's})$, statistical confidence (65%–98%), acoustic anomaly breakdown, and clinical recommendations.
   - Output classifications:
     - `“Parkinson’s Detected”`
     - `“Healthy / No Parkinson’s Detected”`

4. **Prediction History**:
   - Local database persistence via Room.
   - Chronological historical log with date/time, confidence badge, and detailed feature recall.
   - Individual deletion and full database reset.

5. **Comprehensive Medical Education**:
   - Pathophysiology of dopamine neuron degeneration in the substantia nigra.
   - Why voice measurement matters in early screening (micro-dysphonia precedes overt motor tremors).
   - Machine learning's role in acoustic signal processing and its limitations.

6. **Interactive Workflow Architecture**:
   - Interactive 7-step visual diagram detailing the transformation from sustained vowel phonation (/a/) to acoustic feature extraction, z-score normalization, model inference, and recommendation generation.

## 🛠 Tech Stack

- **Framework**: Modern Android SDK (Jetpack Compose, Material Design 3)
- **Language**: Kotlin 2.x
- **Architecture**: MVVM (Model-View-ViewModel) + Clean Architecture
- **Data Persistence**: Android Room Database with reactive Kotlin Flow
- **Build System**: Gradle (Kotlin DSL - `.gradle.kts`)
